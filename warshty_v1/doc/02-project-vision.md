# Project Vision

## 1. Project Name
**ورشتي** — نظام إدارة ورش النجارة | ERP متكامل للديون والنقدية والشغلانات

---

## 2. Problem Statement
حالياً إدارة الشغلانات والدفعات والأرباح وديون الأشخاص تتم بشكل يدوي أو شبه يدوي، مما يؤدي إلى:

- **فقدان تتبع الأرباح الحقيقية** — عدم وجود نظام موحد لتكاليف الخامات والمصنعيات
- **صعوبة معرفة حالة كل شغلانة** — هل خلصت؟ مستلمة؟ باقيها فلوس؟
- **صعوبة متابعة الدفعات والمستحقات** — مين دافع كام ومين لسه عليه كام
- **خلط الديون الشخصية بالخزنة** — أخذت من فلان وديته لفلان يتخبط مع وارد الخزنة ومصروفها
- **عدم وجود تقارير واضحة** — معرفش كل شهر كسبت كام ولا خسرت كام ولا مين مديون ليّ بكام

---

## 3. Solution
نظام محلي (Offline First — Single HTML File) متكامل يعتمد على **الفصل التام بين دفترين**:

1. **دفتر الديون (Debt Register):** حسابات الأشخاص — كل شخص ليه حساب بالدين والعطا
2. **دفتر النقدية (Cash Register):** الخزنة — واردات ومصروفات الورشة

بالإضافة إلى:
- **إدارة الشغلانات:** تتبع كل شغلانة من البداية إلى التسليم
- **التقارير المالية:** أرباح/خسائر، تقارير الأشخاص، تقارير الشغلانات

كل حاجة في ملف HTML واحد — شغال على الموبايل والكمبيوتر — بدون إنترنت.

---

## 4. System Type
**Private System with Master Password**

- دخول بكلمة سر رئيسية (Master Password)
- مستخدم واحد — المالك فقط (م. مصطفى)
- لا يوجد Multi-user أو صلاحيات متعددة
- تخزين محلي بالكامل (localStorage) — لا يوجد Server

---

## 5. Core Features

### 5.1 إدارة الأشخاص (Persons CRM)
- قاعدة بيانات لجميع جهات الاتصال (عملاء — موردين — صنايعية — شركات — موظفين)
- كل شخص ليه **حساب ديون مستقل** بأخذت/عطيت
- صفحة تفاصيل الشخص: حساب شخصي + شغلاناته
- تقرير شخص مفصل جداً: عليا كام / دافع كام + تفاصيل كل معاملة

### 5.2 دفتر الديون (Debt Register)
- معاملات أخذت (↑) وعطيت (↓) فقط
- عرض الرصيد قبل وبعد كل معاملة
- تعديل وحذف المعاملات
- لا تؤثر معاملات الديون على الخزنة إطلاقاً

### 5.3 الخزنة (Cash Register)
- واردات ومصروفات الورشة
- قائمة مختلطة (وارد + مصروف) مرتبة زمنياً
- تصنيفات لكل عملية
- إمكانية ربط المصروف بشغلانة معينة
- لا تؤثر معاملات الخزنة على ديون الأشخاص إطلاقاً

### 5.4 إدارة الشغلانات (Jobs)
- إنشاء شغلانة: عميل، ورشة، نوع، مبلغ متفق عليه
- هيكل تكاليف الشغلانة:
  - **الخامات:** إضافة متعددة (الوصف × الكمية × سعر الوحدة)
  - **المصنعيات:** بنود أجرة النجار والدهان والتركيب والعامل
  - **تكاليف أخرى:** نقل، صيانة، إيجار معدات، إلخ
- تسجيل الدفعات مع auto-ledger للخزنة
- حساب الربح: المتفق عليه − (الخامات + المصنعيات + تكاليف أخرى)
- فلترة حسب الورشة (سيلا / الفيوم) وحسب الحالة (نشط / مكتمل / باقي تحصيل)

### 5.5 التقارير (Reports)
- **تقرير الأرباح والخسائر (P&L):** إجمالي الإيرادات والمصروفات + صافي الربح
- **تقرير الأشخاص (مفصل جداً):** لكل شخص — عليا كام، دافع كام، الرصيد، الشغلانات
- **تقرير الشغلانات:** القيمة، التكاليف، الربح، النسبة
- فلترة زمنية: الكل / شهر / سنة

### 5.6 التصنيفات (Categories)
- إدارة تصنيفات المصروفات والواردات والمصنعيات
- إضافة وتعديل وحذف التصنيفات حسب احتياج الورشة

### 5.7 الأمان
- كلمة سر رئيسية مشفرة (SHA-256)
- 5 محاولات فاشلة → تأخير 30 ثانية
- Remember token للبقاء مسجلاً
- تأكيد قبل حذف أي بيانات

## 6. Design Principles

### 6.1 الفصل التام بين الدفترين
```
دفتر الديون ← مستقل تماماً ← الخزنة
       │                            │
       ├── لا يؤثر على الخزنة      ├── لا تؤثر على الديون
       └── أخذت/عطيت فقط           └── وارد/مصروف فقط
```

### 6.2 Single Source of Truth
- كل معلومة مالية موجودة في مكان واحد
- الربح يُحسَب ولا يُخزَّن
- الرصيد يُحسَب ولا يُخزَّن

### 6.3 Mobile-First
- أقصى عرض 430px
- Bottom Navigation
- Bottom Action Bar في الشاشات الرئيسية
- دعم safe-area-inset-bottom

### 6.4 Offline-First
- كل البيانات في localStorage
- لا يحتاج إنترنت إطلاقاً
- ملف HTML واحد — شغال من الفلاشة
